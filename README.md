# Piss Gnomes: Last Gnome Standing (mobile/tablet)

A top-down, third-person spin-off of Piss Gnomes made for phones and tablets. Ten gnomes, one small enchanted forest,
pee is the only weapon, and a closing mist forces a finish. Last gnome standing wins.

## Play

Open `piss-gnomes-mobile.html` in a browser (self-contained, no install). On iPad/iPhone, use Share > Add to Home Screen.

- **Touch:** left thumb walks, right thumb aims and pees (a light auto-aim helps). Portrait and landscape both work.
- **Computer:** WASD to walk, mouse to aim, hold click or Space to pee.
- **Bladder:** drains as you pee and refills when you stop. Run dry and you wait for it to come back.

## Develop

```bash
npm install
npm run dev     # dev server
npm run build   # single-file dist/index.html
```

Built with TypeScript, Vite and Three.js. Add `?god` to the URL to be invulnerable while testing.
